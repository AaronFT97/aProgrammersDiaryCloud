My Concerns on AI as an Aspiring Developer

The Journey

I enrolled into a Web Development course. After spending some time on essential tooling like Linux, command line or Git and grasping some of the internet concepts, the time for learning the core web technologies have arrived. Not gonna lie, setting my virtual machine and getting used to Xubuntu while figuring out to optimize performance and reduce stuttering was... fascinating.

Next Step: The Foundations of the Web

This is the current state I am in my learning process. I'm killing two birds with one stone by doing writing (a passionate hobby), and practicing the most common tags for this simple HTML file. HTML is the next step. Maybe it'll take me less than a month to learn the structure and most common tags before moving to CSS.

CSS and JavaScript are also awaiting

You know, alongside HTML, the core technologies for everything you see on your screen when opening a web browser are also a must. Cannot wait to learn JS, though!

AI can already do almost all of this

You prompt, and AI generates the code for you. It's still not perfect, but it's getting better in a matter of... months.

Many people who even work in the industry say there's no need to learn to code anymore. And massive layoffs in the IT industry are being constant. Most senior developers are safe from this wave because of their valuable expertise. Because these things still have errors. Junior developers are struggling to land a job, though.

Then, what can we expect for people who are just learning these concepts? Will our efforts on learning these things be for naught? I hope they won't as you will always need the fundamentals to start building (and I think this applies for every field of knowledge). Fundamentals stand the test of time, no matter what technologies come and go; they were all created by applying the Computer Science core principles. And somebody has to know how to use these tools (because at the end that's what they are, tools).

Then, aspiring contributors, being a software developer/engineer/programmer has evolved. It always does, but our duty is the same: solving problems.
